Highlights:
\begin{itemize}
\item We demonstrate the existence of space-filling threads that can be constructed by using a single modular element that can be obtained by partitioning a cube into two \textit{yin-yang} type identical pieces. 
\item These \textit{yin-yang} type congruent tiles can directly be constructed by using a parametric approach. 
\item We demonstrated that these tiles can be made foldable, i.e. they can be constructed by folding planar materials.
\item We show that there exist infinitely many such congruent tiles. 
\item We further demonstrate that any 2-way 2-fold woven structure can be constructed by translated and rotated versions of such congruent tiles.
\end{itemize}
